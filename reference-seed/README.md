# Reference Seed

This is a deliberately small, non-production Seed implementation for protocol interoperability and local development.

It implements signed `join`, `renew`, `leave`, capability `discover`, and a no-op unreachable report endpoint through the public A2A transport. It intentionally does **not** implement LivingRuntime production reputation, anti-Sybil policy, federation operations, Explorer/operator functionality, or deployment policy.
